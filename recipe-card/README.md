### What I learned

Working on this project was a great practice for structuring readable content using semantic HTML and matching a visual layout closely using custom styling. I focused on clean spacing, custom list markers for ingredients and instructions, and building a structured nutritional info grid table.

```css
.nutrition-row {
  display: flex;
  justify-content: space-between;
  padding: 12px 24px;
  border-bottom: 1px solid var(--stone-150);
}```
